# QuizLearn

**Μάθε • Εξασκήσου • Αξιολογήσου**

Responsive εφαρμογή **εξάσκησης και αυτοαξιολόγησης** με δυνατότητα χρήσης διαφορετικών τραπεζών ερωτήσεων.

Η εφαρμογή λειτουργεί στον browser, χωρίς JavaScript framework, και υποστηρίζει Μελέτη, Εξέταση, Τυχαίο Quiz, Αγαπημένες, Στατιστικά, Ρυθμίσεις, επιλογή εξωτερικού αρχείου ερωτήσεων και δημιουργία νέας τράπεζας ερωτήσεων από αρχεία DOCX.

> **Σημείωση:** Το QuizLearn αποτελεί ανεξάρτητο εργαλείο μελέτης και αυτοαξιολόγησης. Δεν αποτελεί επίσημη εφαρμογή, επίσημη τράπεζα θεμάτων ή επίσημο εξεταστικό σύστημα φορέα πιστοποίησης.

## ✨ Βασικές λειτουργίες

- 📚 **Μελέτη** — εξάσκηση στην ενεργή τράπεζα ερωτήσεων με άμεση ανατροφοδότηση, υπόδειξη και επεξήγηση.
- 🎓 **Εξέταση** — προσομοίωση εξέτασης με παραμετροποιήσιμο πλήθος ερωτήσεων και υποχρεωτικών απαντήσεων.
- 🎲 **Τυχαίο Quiz** — δημιουργία Quiz με τυχαία επιλεγμένο το μισό της ενεργής τράπεζας ερωτήσεων.
- ⭐ **Αγαπημένες** — αποθήκευση ερωτήσεων και ξεχωριστή εξάσκηση μόνο σε αυτές.
- 💡 **Υποδείξεις και επεξηγήσεις** — υποστήριξη της μελέτης ανά ερώτηση.
- 🔄 **Επανάληψη λαθών** — νέο Quiz με τις λανθασμένες και παραλειφθείσες ερωτήσεις.
- 📊 **Στατιστικά** — καλύτερη επίδοση, τελευταίο σκορ, προσπάθειες, ακρίβεια, σωστές και λανθασμένες απαντήσεις.
- ⚙️ **Ρυθμίσεις** — τυχαία σειρά ερωτήσεων και απαντήσεων, ήχοι, χρονόμετρο, ρυθμίσεις εξέτασης και επαναφορά προόδου.
- 📂 **Επιλογή αρχείου Quiz** — φόρτωση εξωτερικού αρχείου ερωτήσεων `.js` και χρήση του ως ενεργής τράπεζας.
- 🛠️ **Δημιουργία Quiz από DOCX** — μετατροπή αρχείων DOCX σε `questions-generated.js`.
- 📱 **Responsive σχεδίαση** — προσαρμοσμένη εμφάνιση σε υπολογιστή, tablet και κινητό.
- 💾 **Τοπική αποθήκευση** — αποθήκευση προόδου, στατιστικών, ρυθμίσεων και αγαπημένων στον browser.
- 📲 **PWA υποδομή** — `manifest.json` και Service Worker για cache βασικών αρχείων.

## 🚀 Εκκίνηση

Κατεβάστε ή κάντε clone το repository και ανοίξτε το `index.html` σε σύγχρονο browser.

```bash
git clone <URL-ΤΟΥ-REPOSITORY>
cd QuizLearn
```

Για την πληρέστερη λειτουργία του Service Worker/PWA συνιστάται η εκτέλεση μέσω τοπικού web server ή η δημοσίευση μέσω GitHub Pages. Ο Service Worker απαιτεί περιβάλλον HTTP/HTTPS και δεν ενεργοποιείται όταν η εφαρμογή ανοίγει απευθείας με `file://`.

## 📚 Μελέτη

Η λειτουργία **Μελέτη** χρησιμοποιεί την ενεργή τράπεζα ερωτήσεων. Ο χρήστης μπορεί να απαντά στις ερωτήσεις, να βλέπει άμεση ανατροφοδότηση, υπόδειξη και επεξήγηση και να μετακινείται μεταξύ των ερωτήσεων.

## 🎓 Λειτουργία Εξέτασης

Η λειτουργία **Εξέταση** επιλέγει τυχαίες ερωτήσεις από την ενεργή τράπεζα.

Το πλήθος των ερωτήσεων και ο ελάχιστος αριθμός υποχρεωτικών απαντήσεων καθορίζονται από τις **Ρυθμίσεις Εξέτασης**.

Οι επιτρεπόμενες παραλείψεις υπολογίζονται αυτόματα:

`Παραλείψεις = Πλήθος ερωτήσεων − Υποχρεωτικές απαντήσεις`

Οι προεπιλεγμένες τιμές είναι **48 ερωτήσεις** και **42 υποχρεωτικές απαντήσεις**, επομένως επιτρέπονται έως **6 παραλείψεις**.

Κατά τη διάρκεια της εξέτασης εμφανίζονται δυναμικοί μετρητές απαντημένων και παραλειφθεισών ερωτήσεων. Στο τέλος παρουσιάζονται το σκορ, οι σωστές και λανθασμένες απαντήσεις, οι παραλείψεις και ο συνολικός χρόνος.

## 🎲 Τυχαίο Quiz

Η λειτουργία **Τυχαίο Quiz** δημιουργεί Quiz με τυχαία επιλεγμένο το **μισό της ενεργής τράπεζας ερωτήσεων**. Αν το πλήθος των ερωτήσεων είναι μονό, χρησιμοποιείται στρογγυλοποίηση προς τα πάνω.

## ⭐ Αγαπημένες

Με το σύμβολο **☆** μια ερώτηση προστίθεται στις Αγαπημένες και εμφανίζεται ως **⭐**.

Από την ενότητα **Αγαπημένες** μπορείτε:

- να δείτε τις αποθηκευμένες ερωτήσεις,
- να ξεκινήσετε Quiz μόνο με αυτές,
- να αφαιρέσετε μεμονωμένες ερωτήσεις,
- να διαγράψετε όλες τις αγαπημένες με την επιλογή **Εκκαθάριση**.

## 📂 Επιλογή εξωτερικού αρχείου Quiz

Από τις Ρυθμίσεις μπορεί να επιλεγεί εξωτερικό αρχείο ερωτήσεων `.js`. Η εισαγόμενη τράπεζα γίνεται η ενεργή τράπεζα και χρησιμοποιείται στις λειτουργίες **Μελέτη**, **Εξέταση** και **Τυχαίο Quiz**.

Η προεπιλεγμένη τράπεζα της εφαρμογής βρίσκεται στο:

```text
data/questions.js
```

## 🎓 Ρυθμίσεις Εξέτασης

Από την επιλογή **Ρυθμίσεις Εξέτασης** μπορείτε να προσαρμόσετε:

- **Πλήθος ερωτήσεων εξέτασης** — καθορίζει πόσες ερωτήσεις θα περιλαμβάνει η εξέταση.
- **Υποχρεωτικές απαντήσεις** — καθορίζει σε πόσες ερωτήσεις πρέπει τουλάχιστον να απαντήσει ο χρήστης.
- **Επιτρεπόμενες παραλείψεις** — υπολογίζονται αυτόματα από τη διαφορά μεταξύ των δύο παραπάνω τιμών.

Οι επιλεγμένες τιμές αποθηκεύονται στις ρυθμίσεις της εφαρμογής και χρησιμοποιούνται κάθε φορά που ξεκινά νέα Εξέταση.

## 🛠️ Δημιουργία Quiz από DOCX

Η εφαρμογή περιλαμβάνει εργαλείο μετατροπής αρχείων **DOCX → questions.js**.

Η λειτουργία ανοίγει από:

**Ρυθμίσεις → Δημιουργία Quiz → Δημιουργία**

Το εργαλείο βρίσκεται στον φάκελο:

```text
DOCX_to_questions_HTML/
```

και χρησιμοποιεί το αρχείο:

```text
docx-to-questions.html
```

### Διαδικασία

1. Επιλέξτε ένα ή περισσότερα αρχεία DOCX.
2. Το **Category** προκύπτει αυτόματα από το όνομα του αρχείου και μπορεί να διορθωθεί στον πίνακα.
3. Ελέγξτε τα πεδία **Chapter** και **Category** για κάθε DOCX.
4. Το **Difficulty** διαβάζεται ξεχωριστά από κάθε ερώτηση και πρέπει να έχει τιμή `easy`, `medium` ή `hard`.
5. Ελέγξτε την προεπισκόπηση και τυχόν προειδοποιήσεις.
6. Πατήστε **💾 Δημιουργία questions.js**.
7. Δημιουργείται το αρχείο `questions-generated.js`.

Η σειρά των επιλεγμένων DOCX καθορίζει τη σειρά των κεφαλαίων. Για την ανάγνωση DOCX το εργαλείο χρησιμοποιεί **Mammoth.js**, το οποίο φορτώνεται από CDN, επομένως για τη συγκεκριμένη λειτουργία απαιτείται σύνδεση στο Internet.

### Μαθηματικοί τύποι

Το QuizLearn υποστηρίζει εμφάνιση μαθηματικών τύπων με **MathJax**. Στα αρχεία DOCX οι τύποι μπορούν να γράφονται σε σύνταξη LaTeX μέσα σε αγκύλες `[ ]`.

Παράδειγμα:

```text
Αν [f(x)=x^2], τότε [f'(x)]=
```

Το εργαλείο μετατροπής μετατρέπει αυτόματα αυτή τη μορφή σε κατάλληλη σύνταξη MathJax κατά τη δημιουργία του αρχείου ερωτήσεων.

## 🛠️ Τεχνολογίες

Η κύρια εφαρμογή έχει υλοποιηθεί με:

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Local Storage
- MathJax
- Web App Manifest
- Service Worker

Δεν χρησιμοποιείται JavaScript framework.

Για τη μετατροπή των αρχείων DOCX, το εργαλείο δημιουργίας Quiz χρησιμοποιεί **Mammoth.js**.
