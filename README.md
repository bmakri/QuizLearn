# QuizLearn
Μάθε - Εξασκήσου - Αξιολογήσου
Το QuizLearn είναι μια διαδικτυακή εφαρμογή μελέτης, εξάσκησης και αυτοαξιολόγησης με ερωτήσεις πολλαπλής επιλογής. Υποστηρίζει την προεπιλεγμένη τράπεζα ερωτήσεων και προσωπικές τράπεζες σε μορφή JSON.

Εφαρμογή: https://bmakri.github.io/QuizLearn/
Αποθετήριο: https://github.com/bmakri/QuizLearn

## Βασικές λειτουργίες
- Μελέτη: εξάσκηση με άμεση ανατροφοδότηση, υποδείξεις και επεξηγήσεις.
- Εξέταση: επιλογή πλήθους ερωτήσεων και υποχρεωτικών απαντήσεων.
- Τυχαίο Quiz: τυχαία επιλογή ερωτήσεων από την ενεργή τράπεζα.
- Αγαπημένες: αποθήκευση και εξάσκηση σε επιλεγμένες ερωτήσεις.
- Στατιστικά: παρακολούθηση επιδόσεων και προσπαθειών.
- Ρυθμίσεις: σειρά ερωτήσεων και απαντήσεων, ήχοι και χρονόμετρο.
- Οι τράπεζές μου: εισαγωγή, αποθήκευση, ενεργοποίηση και διαγραφή τραπεζών JSON.
- Δημιουργία Quiz: μετατροπή ερωτήσεων από DOCX σε JSON.

## Χρήση
Ανοίξτε την εφαρμογή από τον παραπάνω σύνδεσμο ή κατεβάστε το αποθετήριο και ανοίξτε το `index.html` στον browser.
Η προεπιλεγμένη τράπεζα περιλαμβάνει 60 ερωτήσεις. Για χρήση προσωπικής τράπεζας, εισαγάγετε ένα συμβατό αρχείο `.json` από τις Ρυθμίσεις και ενεργοποιήστε το από την ενότητα «Οι τράπεζές μου». Η ενεργή τράπεζα επαναφέρεται όταν ανοίξετε ξανά την εφαρμογή στον ίδιο browser.
Η εφαρμογή μπορεί να λειτουργεί τοπικά χωρίς web server. Στο GitHub Pages υποστηρίζεται και χρήση χωρίς σύνδεση, αφού φορτωθούν και αποθηκευτούν επιτυχώς τα απαραίτητα αρχεία. Ο Service Worker δεν ενεργοποιείται μέσω `file://`.

## Τεχνολογίες
HTML5, CSS3, JavaScript, Local Storage, IndexedDB, MathJax, Web App Manifest και Service Worker. Για τη μετατροπή DOCX χρησιμοποιείται η βιβλιοθήκη Mammoth.js.

## Βασικά αρχεία
- `index.html`: αρχική σελίδα της εφαρμογής.
- `css/style.css`: εμφάνιση.
- `js/app.js`: εκκίνηση εφαρμογής.
- `js/quiz.js`: λειτουργίες Quiz.
- `js/ui.js`: περιβάλλον χρήστη.
- `js/storage.js`: τοπική αποθήκευση.
- `js/banks.js`: διαχείριση προσωπικών τραπεζών.
- `data/questions.js`: προεπιλεγμένες ερωτήσεις.
- `DOCX_to_questions_HTML/docx-to-questions.html`: εργαλείο μετατροπής DOCX σε JSON.
- `service-worker.js`: προσωρινή αποθήκευση αρχείων για offline χρήση.
