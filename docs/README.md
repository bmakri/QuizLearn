# QuizLearn v2.1.0 — Τεχνική τεκμηρίωση

Η τεκμηρίωση συνοδεύει την έκδοση v2.1.0 της εφαρμογής [QuizLearn](https://bmakri.github.io/QuizLearn/).

## Περιεχόμενα

- [Αρχιτεκτονική και υποσυστήματα](architecture.md)
- [Μοντέλο δεδομένων JSON και αποθήκευση](data-model.md)
- [Διαγράμματα και ροές εργασίας](flowcharts.md)
- [Τεχνολογίες και ασφάλεια](technologies.md)
- [Δοκιμές, διάθεση και συντήρηση](testing-maintenance.md)

**Μεθοδολογική σημείωση:** Η τεκμηρίωση βασίζεται στο τεχνικό εγχειρίδιο και στην επιθεώρηση των αρχείων της έκδοσης QuizLearn v1.7. Οι δοκιμές T01–T12 αποτελούν προτεινόμενο πρωτόκολλο ελέγχου και δεν παρουσιάζονται ως εκτελεσμένες.

Στην έκδοση v1.7, στις 25/11/2026 ολοκληρώθηκαν 20 χειροκίνητες λειτουργικές δοκιμές (TC-01 έως TC-20), με αποτέλεσμα 20 PASS και 0 FAIL. Η μεθοδολογία, τα αναλυτικά αποτελέσματα, οι παρατηρήσεις και οι περιορισμοί παρουσιάζονται στην Ενότητα 13 του αρχείου [testing-maintenance.md](testing-maintenance.md).

Τα διαγράμματα περιγράφουν λογικές ροές λειτουργίας και δεν αποτελούν αυτόματα παραγόμενα διαγράμματα UML.

**Άδεια:** Ισχύουν οι όροι του αρχείου `LICENSE` στη ρίζα του αποθετηρίου.

## Επικαιροποίηση v2.1.0 — 27/11/2026

Η επικαιροποίηση της 27/11/2026 βασίζεται στην προηγούμενη τεκμηρίωση και στις επιβεβαιωμένες λειτουργίες της v2.1.0, όχι σε νέα πλήρη επιθεώρηση του τελικού πηγαίου κώδικα. Οι δοκιμές της v1.7 διατηρούνται ως ιστορικά αποτελέσματα. Οι συμπληρωματικοί έλεγχοι καταγράφονται στην ενότητα 14 του [testing-maintenance.md](testing-maintenance.md).
