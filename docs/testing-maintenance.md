## 11. Ανάπτυξη, διάθεση και συντήρηση

Το έργο φιλοξενείται ως στατικό αποθετήριο GitHub. Η εφαρμογή είναι διαθέσιμη στο https://bmakri.github.io/QuizLearn/ και η έκδοση αναφοράς φέρει tag v1.7. Ο Service Worker ορίζει CACHE_NAME = "quiz-v1.7"· κάθε αλλαγή στα cached assets απαιτεί προσεκτική αναβάθμιση της cache.
- Εργασία σε νέο branch για σημαντικές αλλαγές.
- Έλεγχος αλλαγών σε καθαρό browser profile και σε κινητή συσκευή.
- Αναβάθμιση CACHE_NAME όταν αλλάζουν πόροι που αποθηκεύονται.
- Δημιουργία Release με περιγραφή αλλαγών και γνωστών περιορισμών.
- Διατήρηση αντιγράφου προσωπικών τραπεζών μέσω εξαγωγής JSON.
