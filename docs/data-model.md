## 5. Μοντέλο δεδομένων JSON

Μια εξαγόμενη προσωπική τράπεζα αποτελείται από JSON array ερωτήσεων. Το παρακάτω παράδειγμα είναι σχηματικό και διατηρεί τα βασικά πεδία που απαντούν στα δεδομένα του έργου.
{
"id": 1,
"category": "Α_Γυμνασίου",
"difficulty": "medium",
"type": "multiple",
"question": "Ποιος από τους αριθμούς είναι πρώτος;",
"answers": [
"21",
"27",
"29",
"33"
],
"correct": 2,
"hint": "Πρώτος αριθμός έχει ακριβώς δύο θετικούς διαιρέτες.",
"explanation": "Το 29 διαιρείται μόνο με το 1 και το 29.",
"tags": [
"Α_Γυμνασίου"
],
"image": null,
"reference": "ΜΑΘΗΜΑΤΙΚΑ",
"chapter": 1,
"favorite": false
}
| Πεδίο | Αναμενόμενος τύπος | Περιγραφή |
| --- | --- | --- |
| id | number/string | Αναγνωριστικό |
| category | string | Κατηγορία |
| difficulty | string | Βαθμός δυσκολίας |
| type | string | Τύπος ερώτησης |
| question | string | Εκφώνηση |
| answers | array | Εναλλακτικές απαντήσεις |
| correct | number | Μηδενικής βάσης δείκτης σωστής απάντησης |
| hint | string | Υπόδειξη |
| explanation | string | Επεξήγηση |
| tags | array | Ετικέτες |
| image | string/null | Προαιρετική εικόνα |
| reference | string | Πηγή |
| chapter | number/string | Κεφάλαιο |
| favorite | boolean | Σημαία αγαπημένου |
Κρίσιμος κανόνας ακεραιότητας: για ερώτηση πολλαπλής επιλογής, 0 ≤ correct < answers.length. Το απλό JSON.parse ελέγχει σύνταξη και όχι όλες τις σημασιολογικές προϋποθέσεις. Προτείνεται τυπικό JSON Schema και σαφής διαχείριση εκδόσεων σχήματος.

## 5.1 Εγγραφή προσωπικής τράπεζας στην IndexedDB

{
"id": "<UUID>",
"name": "Τράπεζα Μαθηματικών",
"questions": [ { "id": 1, "question": "...", "answers": ["..."], "correct": 0 } ],
"createdAt": "2026-11-25T10:00:00.000Z"
}
Η βάση ονομάζεται QuizLearnDB και το object store banks χρησιμοποιεί keyPath id. Η UUID δημιουργείται με crypto.randomUUID(). Η δομή αυτή δεν πρέπει να συγχέεται με το εξαγόμενο JSON, το οποίο περιέχει μόνο τον πίνακα ερωτήσεων.

## 6. Αποθήκευση και διατήρηση κατάστασης

| Μέσο | Δεδομένα | Περιορισμός |
| --- | --- | --- |
| IndexedDB | Προσωπικές τράπεζες και μεταδεδομένα | Ανά browser/origin, δυνατότητα διαγραφής από χρήστη |
| localStorage | Ρυθμίσεις, στατιστικά, αγαπημένα, αναγνωριστικό ενεργής τράπεζας | Δεν είναι ασφαλής χώρος για μυστικά |
| Cache Storage | Πόροι εφαρμογής | Εξαρτάται από πολιτική cache και επιτυχή εγκατάσταση SW |
| JSON export | Φορητό αντίγραφο τράπεζας | Απαιτεί χειροκίνητη φύλαξη/μεταφορά |
Η ενεργή τράπεζα αναφέρεται στο localStorage με το κλειδί quizlearn_active_bank. Κατά την εκκίνηση γίνεται προσπάθεια ανάκτησης της αντίστοιχης εγγραφής IndexedDB. Η απώλεια δεδομένων browser δεν αποκαθίσταται χωρίς προηγούμενη εξαγωγή.
