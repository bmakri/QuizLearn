## 8. Τεχνολογικές επιλογές

| Επιλογή | Λόγος | Αντιστάθμισμα |
| --- | --- | --- |
| HTML/CSS/JavaScript | Εκτέλεση σε browser, εύκολη διάθεση | Απαιτεί πειθαρχία στη δομή modules |
| JSON | Φορητό, αναγνώσιμο format | Χρειάζεται schema validation |
| IndexedDB | Δομημένη ασύγχρονη αποθήκευση | Εξαρτάται από τον browser |
| localStorage | Απλή αποθήκευση μικρών τιμών | Περιορισμένη χωρητικότητα/ασφάλεια |
| Mammoth.js | Ανάγνωση περιεχομένου DOCX | Πιθανές αποκλίσεις στη μορφοποίηση |
| MathJax | Μαθηματική στοιχειοθεσία | Εξάρτηση φόρτωσης/διαθεσιμότητας |
| Service Worker | Offline cache | Χρειάζεται διαχείριση εκδόσεων |
| GitHub Pages | Απλή στατική φιλοξενία | Χωρίς εγγενές server-side API |

## 9. Ασφάλεια και προστασία δεδομένων

Η τοπική αποθήκευση μειώνει την ανάγκη αποστολής προσωπικών τραπεζών σε server, δεν αποτελεί όμως εγγύηση πλήρους ασφάλειας. Αρχεία JSON και DOCX θεωρούνται μη έμπιστη είσοδος. Απαιτείται έλεγχος τύπων/μεγέθους, ασφαλής εμφάνιση κειμένου, έλεγχος δυναμικού HTML και περιορισμός εξωτερικών πόρων.
- Να αποφεύγεται η χρήση innerHTML με μη έμπιστο περιεχόμενο χωρίς κατάλληλο καθαρισμό.
- Να επαληθεύεται ότι correct είναι έγκυρος δείκτης και ότι οι απαντήσεις είναι μη κενές.
- Να εξεταστεί Content Security Policy συμβατή με MathJax και τα υπάρχοντα scripts.
- Να ελεγχθεί η συμπεριφορά σε κατεστραμμένα αρχεία, πολύ μεγάλες τράπεζες και αποτυχίες IndexedDB.
- Να προειδοποιείται ο χρήστης ότι καθαρισμός δεδομένων browser μπορεί να διαγράψει τις τράπεζες.
Οι παραπάνω έλεγχοι είναι προτεινόμενες ενέργειες και όχι πιστοποίηση ότι έχει εντοπιστεί ή αποκλειστεί συγκεκριμένη ευπάθεια.
