QuizLearn — Μετατροπέας DOCX σε JSON

Περιγραφή
Ο μετατροπέας docx-to-questions.html δημιουργεί τράπεζες ερωτήσεων JSON από αρχεία Word (DOCX), για εισαγωγή στο QuizLearn.

Χρήση
1. Άνοιξε το docx-to-questions.html σε Chrome ή Edge ή Firefox.
2. Επίλεξε ένα ή περισσότερα αρχεία DOCX που ακολουθούν το Πρότυπο_Ερωτήσεων.docx.
3. Έλεγξε τα πεδία Chapter και Category για κάθε αρχείο.
4. Έλεγξε την προεπισκόπηση των ερωτήσεων και τις προειδοποιήσεις.
5. Χρησιμοποίησε την επιλογή δημιουργίας/εξαγωγής JSON του μετατροπέα.
6. Εισήγαγε το παραγόμενο JSON στην ενότητα «Οι τράπεζές μου» του QuizLearn και ενεργοποίησέ το από εκεί.

Βαθμός δυσκολίας (Difficulty)
Ο βαθμός δυσκολίας δηλώνεται ξεχωριστά για κάθε ερώτηση, μετά το Hint, με μία από τις τιμές:
    Difficulty easy
    Difficulty medium
    Difficulty hard

Γίνονται επίσης δεκτές μορφές όπως:
    Difficulty: easy
    Difficulty - medium

Αν η τιμή λείπει ή δεν είναι έγκυρη, έλεγξε την αντίστοιχη προειδοποίηση του μετατροπέα. Η προεπισκόπηση επιτρέπει τον έλεγχο της δυσκολίας κάθε ερώτησης.

Μαθηματικοί τύποι (LaTeX / MathJax)
Το QuizLearn υποστηρίζει μαθηματικούς τύπους με LaTeX και MathJax.
Στο DOCX οι τύποι γράφονται μέσα σε αγκύλες [ ].

Παραδείγματα:
    [f(x)=x^2]
    [f'(x)=2x]
    [\frac{1}{x}]
    [\sqrt{x+1}]
    [\lim_{x\to 2}(x+3)]
Οι τύποι μπορούν να χρησιμοποιηθούν σε ερωτήσεις, απαντήσεις, υποδείξεις (Hint) και επεξηγήσεις.
Παράδειγμα: Αν [f(x)=x^2], τότε [f'(x)]=

Προτίμησε τη σύνταξη LaTeX αντί για ειδικούς μαθηματικούς χαρακτήρες μορφοποιημένους στο Word.

Τεχνική σημείωση
Ο μετατροπέας χρησιμοποιεί τη βιβλιοθήκη Mammoth.js για ανάγνωση DOCX. Εφόσον φορτώνεται από CDN, απαιτείται σύνδεση στο Internet για τη φόρτωσή της.

Σημείωση
Οι ακριβείς ετικέτες των κουμπιών και το όνομα του εξαγόμενου αρχείου εξαρτώνται από την εγκατεστημένη έκδοση του docx-to-questions.html.
