# QuizLearn – Usability Evaluation 0.1
Προσχέδιο, όχι για συλλογή δεδομένων. Ανοίξτε το index.html τοπικά ή ανεβάστε τον φάκελο evaluation στο GitHub. Δεν τροποποιεί την κύρια εφαρμογή. Οι σημειώσεις δραστηριοτήτων δεν μεταφέρονται στο Grafis και χάνονται με επαναφόρτωση. Πριν από δημοσίευση: επιβεβαιώστε τη συμβατότητα των δραστηριοτήτων με την έκδοση QuizLearn, προσθέστε δοκιμαστικά αρχεία, εγκρίνετε το πρωτόκολλο και την ενημέρωση/συγκατάθεση, ελέγξτε ανωνυμία και εξαγωγή Grafis, προσθέστε τον δημόσιο σύνδεσμο στο config.js. Η ένδειξη προσχεδίου παραμένει σκόπιμα μέχρι την τελική έγκριση. Αν ο δημόσιος σύνδεσμος χρησιμοποιεί διαφορετικό επίσημο hostname, προσαρμόστε τον έλεγχο στο evaluation.js μετά από επαλήθευση.
